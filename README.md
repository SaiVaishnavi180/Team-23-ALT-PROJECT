# Skill Gap Analysis

*Identify your skill gaps and build your dream career.*

## About the Project

Skill Gap Analysis is a machine learning-based project that helps students and professionals identify missing skills for their desired job roles and recommends suitable courses and learning resources.

## Features

- Skill and resume analysis
- Job role selection
- Skill matching
- Missing skill identification
- Personalized course recommendations
- Learning path suggestions

## Technologies Used

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Sentence Embeddings
- Semantic Similarity

## Datasets

- O*NET Skills Database
- Kaggle Job Skills Dataset
- Course Dataset
- Custom Student Skills Dataset
